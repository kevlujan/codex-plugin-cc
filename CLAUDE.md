# Working with Codex

- You are the boss: plan the work, split it into small tasks and decide what gets built.
- Hand the heavy coding to Codex with `/codex:rescue --background`, one task at a time.
- When Codex finishes, check its work with `/codex:result` before you accept it.
- Before anything ships, run `/codex:review` so Codex checks your work too.
- If you disagree with Codex, run `/codex:adversarial-review` and explain the trade-off to me.
